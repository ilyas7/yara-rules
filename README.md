Mendeteksi malware VBScript yang di-obfuskasi (disamarkan) menggunakan fungsi Tinkturernes dan decoder ekstraksi string Sejrsskjorterne. Malware ini menggunakan WScript.Shell untuk akses sistem, operasi registry, dan muatan (payload) PowerShell yang disisipkan. Aturan ini mengidentifikasi kombinasi unik dari fungsi-fungsi dan pola decoder yang digunakan dalam keluarga malware spesifik ini.
